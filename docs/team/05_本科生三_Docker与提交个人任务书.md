## 3. 具体任务

### A. Docker 操作说明
记录构建目录、容器工作目录、输入/输出挂载、当前支持参数、`--validate-only` 和 `--fixture` 的作用、退出码和日志查看方法。命令必须以当前脚本实际支持内容为准。

### B. 轻量运行脚本
编写 `team_docker_smoke.sh`：
- 使用当前 Dockerfile 构建候选镜像；
- 只读挂载官方自测输入；
- 使用独立临时输出目录；
- 执行当前支持的校验或夹具模式；
- 保存镜像标识、命令、退出码和输出清单；
- 不覆盖其他成员的结果。

### C. 提交清单
根据官方资料整理代码包、方案包、场景数据和报告、技术报告、成果简介及平台要求。官方文件与平台栏目不一致时标记待队长确认。

### D. 集成后容器验证
队长给出候选提交号后，对该版本做容器运行和输出结构检查。处理器未完成时，只报告容器和接口层结果，不宣称算法有效。
