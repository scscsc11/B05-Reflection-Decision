# 个人任务书 04：马子越

**角色：自主场景材料整理、实验数据汇总与证据索引**  
**分支：`task/ug2-scenario-evidence`**

## 1. 任务定位

队长负责自主场景内容和技术结论，你负责将确认后的材料规范化整理，并汇总已有实验记录。不要自行改变场景核心设定。

## 2. 你负责的文件

```text
data/team_scenario/
docs/scenario/SCENARIO_PACKAGE_CHECK.md
docs/experiments/EVIDENCE_INDEX.md
dev/tests/check_scenario_package.py
dev/tests/export_experiment_summary.py
```

## 3. 具体任务

### A. 场景材料整理
收到队长确认的场景内容后，整理到 `data/team_scenario/`。清单记录文件名、用途、报告章节、版本日期和确认状态。发现数据与报告不一致时，列出差异交队长处理。

### B. 材料一致性检查
创建 `check_scenario_package.py`，检查文件存在性、JSON 可解析性、必需字段、类型、矩阵/向量维度、有限数值和报告引用文件是否存在。只做格式和一致性检查，不生成专用决策数据。

### C. 实验证据汇总
创建 `export_experiment_summary.py`，只读读取现有结果。每项记录包含实验名称、代码版本、数据来源、模型/网关来源、结果路径、请求次数、耗时和结论限制。

必须区分官方 IO 校验、固定值夹具、脚本化网关、进程内替身、真实模型调用和官方正式评测。没有证据的内容标注“未开展”。

### D. 交付证据索引
创建 `EVIDENCE_INDEX.md`，让报告中的每个实验数字都能追溯到对应结果 JSON、日志或提交号。
