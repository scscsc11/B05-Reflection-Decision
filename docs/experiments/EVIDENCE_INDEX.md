## 1. 证据来源分类（必须区分）

| 类别 | 说明 |
| --- | --- |
| 官方 IO 校验 | 官方自测数据 + 双目录输出的格式/契约验证，不等于功能正确 |
| 固定值夹具 | 固定返回值替身，用于跑通流程，不反映真实算法效果 |
| 脚本化网关 | 预设脚本模拟的网关响应，非真实模型 |
| 进程内替身 | 进程内 mock/stub，用于单元或集成测试 |
| 真实模型调用 | 真实大模型接入后的运行结果 |
| 官方正式评测 | 官方正式评测提交与结果 |

结果 JSON 中用 `evidence_type` 字段标识，取值为上表英文键（`official_io` / `fixed_fixture` / `scripted_gateway` / `in_process_stub` / `real_model` / `official_eval`，也接受中文类别名）。未标注或无法判定者列为"未识别/待确认"。
